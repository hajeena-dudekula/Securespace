# SecureSpace

SecureSpace is a secure document-sharing platform developed for the Snovasys Fresher Hiring Challenge 2026.

## Technology Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Objective
Secure document sharing with role-based access control, document-level permissions, and an auditable history of document activities.
